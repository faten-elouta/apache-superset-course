*Un tableau de bord est aussi un récit de données, s'il réussit à être clair et efficace.*

## Comprendre le tableau de bord : définition, objectifs et exemples

**Avant de regarder la vidéo**, il faut comprendre qu'un tableau de bord n'est pas seulement une page avec des graphiques. C'est un outil de pilotage qui aide un responsable à suivre une situation, comparer les résultats avec les objectifs, repérer les écarts et prendre une décision.

On peut partir d'une question simple :

**Quand une personne doit gérer une activité, comment peut-elle savoir rapidement si tout fonctionne bien ou s'il y a un problème ?**

Par exemple, dans une entreprise, un responsable peut vouloir suivre :

- le chiffre d'affaires ;
- le nombre de clients ;
- les retards de livraison ;
- les réclamations ;
- les coûts ;
- les objectifs atteints ou non atteints.

Ces informations deviennent utiles lorsqu'elles sont organisées sous forme d'indicateurs dans un tableau de bord.

Pendant la vidéo, essayez d'identifier trois éléments :

1. la définition du tableau de bord ;
2. les principes de conception ;
3. les éléments visuels ou indicateurs utilisés.
